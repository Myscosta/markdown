## Condições 
> if, switch , ternarios 

***Condições*** é o metodo para **validar** se uma informação é verdadeira, caso seja verdadeira condição aplicada `if` executa somente o código que esta dentro dele, com isso temos condições para que o código execute somente o necessário.

<!--  para dar destaque a palavras dentro de um um texto vc pode usar **palavra** ou __palavra__ para deixar em NEGRITO, e *palavra*  ou _palavra_ para deixar em ITÁLICO,  ou até mesmo ***palavra*** ou ___palavra___ para deixar tanto NEGRITO como ITÁLICO e O `codigo` para referenciar trechos de um código.  -->

```csharp
if (valor1 == valor2)
{
    MessageBox.Show ("Os números são iguais");
}
```
